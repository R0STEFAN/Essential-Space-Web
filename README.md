# ESSENTIAL SPACE // WEB DASHBOARD

Повноцінний самостійний веб-сервіс (Self-Hosted) для читання, відтворення та керування всіма вашими нотатками, аудіозаписами з розпізнаванням Whisper, чеклистами To-Do та закладками з додатку **Nothing OS Essential Space**.

Розроблено у фірмовому стилі Nothing OS (Dot-matrix шрифти, монохромна естетика, червоний акцент Nothing Red `#D71921`, Bento Grid розмітка) та готовий до розгортання в **Coolify** з власним доменом.

---

## 🌟 Ключові можливості

* **Багатокористувацька система (Multi-User)**:
  * Вхід через **Nothing Account** (Email + Пароль або Bearer Token).
  * Кожен користувач заходить під своїм акаунтом і бачить **лише свої особисті хмарні нотатки**.
  * Повна ізоляція даних між різними обліковими записами.
* **Підтримка всіх типів контенту Nothing OS**:
  * 🎙️ **Аудіо-нотатки**: вбудований звуковий плеєр, звукова хвиля та повний текст розшифровки **Whisper AI** з можливістю копіювання в один клік.
  * ☑️ **Чеклисти (To-Do & Tasks)**: інтерактивні галочки з миттєвим збереженням стану, індикатори часу та прогрес виконання.
  * 🔗 **Веб-закладки (Links)**: OpenGraph банери, фавіконки, доменні імена та прямі переходи.
  * 📝 **Текстові нотатки & Clipped Text**: збережені нотатки, фрагменти тексту з екрана Nothing OS.
  * 📁 **Колекції**: фільтрація за папками та категоріями з підрахунком карток.
  * 🗑️ **Кошик (Bin)**: перегляд видалених карток.
* **Повнотекстовий пошук**: миттєва фільтрація за назвою, вмістом нотаток або текстом розшифровки Whisper.

## 🚀 Розгортання на сервері з Coolify

### Крок 1: Створення застосунку в Coolify
1. У панелі Coolify перейдіть до вашого проекту та натисніть **+ New** -> **Application**.
2. Оберіть **Public Git Repository** (або завантажте цю папку `web/` у свій Git-репозиторій) або оберіть **Docker Compose / Dockerfile**.
3. Вкажіть робочу директорію (`Base Directory: /web` або корінь, якщо репозиторій містить тільки веб-сервіс).

### Крок 2: Налаштування власного домену
1. У полі **Domains** введіть ваш домен, наприклад:
   `https://notes.yourdomain.com`
2. Coolify автоматично згенерує безкоштовний SSL-сертифікат через Let's Encrypt за допомогою Traefik.

### Крок 3: Налаштування змонтованого тома (Persistent Volume)
У розділі **Storages**:
* **Name**: `essential_data`
* **Destination path**: `/app/data`
*(Це гарантує, що база даних та кеш нотаток зберігаються при перезапусках контейнера).*

### Крок 4: Змінні оточення (Environment Variables)
У розділі **Environment Variables** додайте:
```env
NODE_ENV=production
PORT=3000
DATA_DIR=/app/data
SESSION_SECRET=згенерований_випадковий_ключ_на_64_символи
NOTHING_API_URL=https://essential-space.nothingtech.link/essentialSpace
```

### Крок 5: Запуск
Натисніть кнопку **Deploy**. Coolify збере Docker-образ і за кілька секунд сервіс буде доступний у будь-якій точці світу!

## 💻 Локальний запуск для розробки

```bash
cd web
npm install
npm run dev
```

Відкрийте в браузері [http://localhost:3000](http://localhost:3000).

## 🔐 Як увійти в систему

1. **Звичайний вхід (Nothing Account)**:
   * Введіть Email вашого Nothing Account.
2. **Вхід за токеном (Token / ADB)**:
   * Якщо ви отримали `accessToken` безпосередньо з системного додатку `com.nothing.user.center`, перейдіть на вкладку **TOKEN / ADB** і вставте його.
3. **Демо-режим**:
   * Натисніть **"Or explore with Demo Account & Sample Notes"** для миттєвого ознайомлення з усіма типами віджетів та контенту без введення пароля.
